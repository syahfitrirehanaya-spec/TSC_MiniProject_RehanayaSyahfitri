# SISTEM MANAJEMEN PERPUSTAKAAN
Program ini dibuat untuk mengelola sistem perpustakaan melalui terminal dengan fitur CRUD (Create, Read, Update, Delete) dan pencarian buku berdasarkan id dan keyword (judul/penulis).

## Cara Menjalankan Program
- Install Node.js terlebih dahulu
- Jalankan program pada terminal dengan memasukkan : node main.js

## Format Data Buku
Data buku disimpan di dalam array sebagai object.

{
    id: 1,
    title: "Laut Bercerita",
    author: "Leila S Chudori",
    year: 2022,
    available: true
}

## Function CRUD
- Create: Untuk menambahkan data buku baru.
- Read: Untuk menampilkan seluruh data buku dalam tabel.
- Update: Untuk memperbarui data buku
- Delete: Untuk menghapus data buku berdasarkan id.
